linux-ntfs-akmod-dev

Source amont:
Namjae Jeon's linux-ntfs
Branch:
ntfs-next

Mise à jour d'une nouvelle version ntfs-next:

1. Récupérer le nouveau commit amont

- Mettre à jour le dépôt linux-ntfs
- Noter le nouveau hash de commit
- Mettre à jour documentation/ntfs-next-commit.txt


2. Créer le nouveau tarball source

Nom recommandé:

linux-ntfs-ntfs-next-<commit-court>.tar.gz

Copier dans:

SOURCES/


3. Mise à jour du spec RPM

Modifier:

Version:

dans SPECS/linux-ntfs-kmod.spec


Ajouter une entrée %changelog:

- Date
- Mainteneur
- Version-release
- Description du changement


4. Construire le SRPM

Commande:

rpmbuild -bs SPECS/linux-ntfs-kmod.spec


5. Construire les RPM

Commande:

rpmbuild -ba SPECS/linux-ntfs-kmod.spec


6. Tester akmods

Installer:

linux-ntfs-kmod-common
akmod-linux-ntfs


Forcer la génération:

sudo akmods --force --akmod linux-ntfs


Vérifier:

find /lib/modules/$(uname -r) -name "ntfs.ko*"

modinfo ntfs


7. Tests fonctionnels

- chargement module:
  sudo modprobe ntfs

- montage NTFS

- test symlink natif:

native_symlink=raw

- test compatibilité WSL:

symlink=wsl
